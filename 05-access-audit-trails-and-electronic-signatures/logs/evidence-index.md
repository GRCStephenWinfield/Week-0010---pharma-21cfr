## 0. What is in this index and what is not

**A correction to Phase 04, recorded rather than smoothed.** `04.13 §8` states, as published, that
*"Phase 05 opens document IDs `HLX-DI-2026-5NN`."* **That statement is superseded, and as published it is
wrong.** Phase 05 speaks as at 2027-01-29 and the year segment carries the year of the phase's vantage, so
the block is **`HLX-DI-2027-500` to `-513`**. **Phase 04 is not edited**; the original stands with this
correction recorded against it, on the discipline Phase 02's evidence index `§0` set for `EV-129`. **No
identifier already issued changes meaning.** **`EV-441` to `EV-500` are permanently unused and are never
issued**, on the same rule that left `EV-129`–`EV-200`, `EV-233`–`EV-300` and `EV-337`–`EV-400` unused.

**Every item below exists at the vantage.** Nothing in this index is a plan, and no item is dated after
2027-01-29.

**This is the first evidence index in this repository that contains a result, and the discipline that
matters most is the ordering.** An index in which a result is dated before the thing it is a result of has
described a conclusion that was reached first and evidenced afterwards. **Every counting item here is dated
on or after the last item it counts.** The instruments come first: the assessment method at `EV-503` is
dated 2026-12-10, the control position record at `EV-507` is dated 2026-12-22, and the six hundred and
seventy-one completed records at `EV-523` are dated 2027-01-20. The register at `EV-522` post-dates the
records it is built from; the reconciliation at `EV-521` post-dates them too. The enumeration of human
readable forms at `EV-514` post-dates the enumeration of signature systems at `EV-515` that it enumerates
forms for; the test records at `EV-516` post-date it; the finding at `EV-517` **is dated no earlier than**
the test records, and the gap reconciliation at `EV-525` **is dated no earlier than** the 34 gap records at
`EV-524` it reconciles. **Where two items carry the same date the weaker relation is the one stated**, because a
strict *post-dates* asserted of a same-day pair is a claim the Date column does not support. **§3 sets that
rule out and §2 shows where it bites.**

**What is not here.** **No executed validation package, no protocol, no test result and no validation
summary report produced under Phase 04's framework** — none exists. **No system validation plan**: the
framework requires one per system and not one has been written. **No deviation record, no CAPA record and
no remediation plan** — none arises from this phase, and **a control gap is not a deviation.** **No
retention schedule entry for any of the 34 in-scope record types** — Phase 07. **No chromatography-specific
assessment** — Phase 06. **No periodic review, no internal audit of the remediated programme, no
third-party audit report, and no inspection record after 2026-02-13.**

**Nothing in this index is a certification, an approval or an attestation of compliance by any agency.**
**There is no Part 11 certification**, and no artefact here could be one.

**On the numbering.** One `EV` block per phase, `EV-5nn` for Phase 05, matching document IDs
`HLX-DI-2027-5NN` — the block `§0` records the correction to. **No identifier already issued changes
meaning:** `EV-421` is the same artefact it was, and `EV-523` will mean the same artefact in Phase 09 as it
does here.

**Retention.** Each item is retained for at least the life of the determination, decision or register it
supports. For the two registers at `EV-522` and `EV-524` that is for as long as the positions they record
are relied on and for the retention period of the records the systems hold — which **is not stated, because
no retention period exists for any of the 34 record types** (`IS-14`, `DP-18`, `AS-37`).

## 3. Rules the index keeps

| Rule | Statement |
|---|---|
| **It records what exists** | An artefact that has not been produced has no `EV` number. **No item is dated after the vantage, and every date is a weekday** |
| **Nothing counts from something that does not yet exist** | **No item asserting a result is dated before the last item it counts.** `EV-522` post-dates `EV-523`, which post-dates `EV-507`, `EV-510`, `EV-528`, `EV-534` and `EV-509`; `EV-521` post-dates `EV-523`; `EV-517` **is dated no earlier than** `EV-516`, which post-dates `EV-514`, which post-dates `EV-515`; `EV-520` post-dates `EV-519`, which post-dates `EV-518`; `EV-525` **is dated no earlier than** `EV-524`, which post-dates `EV-526`; `EV-529` post-dates both `EV-527` and `EV-528`; `EV-530` and `EV-532` post-date `EV-523`. **The ordering is checkable from the Date column and is meant to be checked** |
| **One artefact, one identifier** | An artefact is indexed once. Later phases cite the same number rather than re-issuing it |
| **Named owners** | Every item has a named individual owner — `ADR-0008` |
| **No result in a template** | The four templates carry no `EV` number. `EV-507`, `EV-508` and `EV-526` are the **approved instruments**; `EV-523`, `EV-524`, `EV-516`, `EV-519`, `EV-528` and `EV-534` are **completed instances** |
| **No validation outcome** | **No item is an executed package, a run protocol, a test result or a validation summary report produced under Phase 04's framework.** None exists — `IS-34` |
| **No discharged obligation** | **No item evidences the discharge of any of the 38.** Discharge requires the evidence named on the obligation record to exist |
| **No deviation and no CAPA** | **No item is a deviation record, a CAPA record or a remediation plan.** **A control gap is not a deviation** |
| **No closed gap** | **No item evidences the closure of any of the 34.** None is closed |
| **No conclusion from `OBS-2` and no disposition of `OBS-4`** | Items record links and nothing more — Phase 06 and Phase 08 |
| **No forecast** | No item supports a statement about what a future inspection or audit will find |
| **No legal conclusion** | No item adjudicates anything or characterises any practice as a violation of anything |
| **Continuity** | Phase 06 opens at `EV-6nn`. **No identifier is reused and none already issued is renumbered** |
