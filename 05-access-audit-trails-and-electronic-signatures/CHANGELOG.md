First issue of the Phase 05 record set, speaking as at the vantage of **2027-01-29**.

| Item | Where |
|---|---|
| **The first control position in the programme.** The unit is **a paragraph of `21 CFR 11.10` on a system** — **11 × 61 = 671 positions**. Never the system alone, never the paragraph alone | `05.02`, ADR-0030, `DEC-503` |
| **Three determinations, and the middle one is the finding: Met and required 302 · Met but not required 218 · Not met 151.** **520 controls are present and 218 of them are required by nothing** — and **a control nothing requires can be withdrawn without a deviation, because no procedure would be breached** | `05.09`, ADR-0031, `IS-29` |
| **`21 CFR 11.50` reaches every human readable form, not the screen.** The printed name, the date and time and **the meaning** *"shall be included as part of any human readable form of the electronic record (such as electronic display or printout)"*. **19 systems execute signatures; all three appear on screen on all 19; the meaning is absent from the exported or printed form on 12** — **Helix had only ever checked the screen** | `05.06`, ADR-0032, `IS-30` |
| **The continuing component is the password, not the user identification code.** `21 CFR 11.200(a)(1)(i)` requires a component *"only executable by, and designed to be used only by, the individual"*, and a user ID is known to others. **7 of the 19 re-prompt for the user ID** | `05.07`, ADR-0033, `IS-31` |
| **Two distinct identification components is not multi-factor authentication**, and this repository never calls it that | `05.07 §2` |
| **THE INVERSION — 23 systems hold a reason-for-change field, which Part 11 does not require, and 14 of them fail `21 CFR 11.10(e)`'s requirement that record changes not obscure previously recorded information, which it does.** Effort spent on a control that is not required, absent on one that is | `05.10`, ADR-0036, `IS-32` |
| **`21 CFR 11.10(e)` says nothing about read or view events and imposes no reason-for-change requirement.** What it requires is that changes not obscure what was recorded before, and retention at least as long as the record | `05.05` |
| **89 of the 151 failures sit in the four paragraphs enforcement discretion reaches in full — and that is not a mitigation.** Discretion is FDA's stated intention, not an exemption; **`21 CFR 211.68` and `21 CFR 211.100(b)` survive it entirely**; and **the position is stated identically inside and outside it** | `05.11`, ADR-0035, `IS-33` |
| **A control assessment is not validation, and neither substitutes for the other.** The evidence Phase 04 requires is still owed in full | `05.01`, ADR-0034, `IS-34` |
| **`21 CFR 11.300(b)` specifies no interval.** *"Part 11 requires 90-day password expiry"* is false, and the phase says so | `05.04` |
| **The 151 Not met positions group into 34 control gaps, `CG-01` to `CG-34`**, each naming its paragraph, its systems, its single cause and what would close it — with **no position double-counted and none omitted** | control gap register |
